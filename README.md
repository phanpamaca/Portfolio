This repository contains screen shots of the following projects:
1. Call Center KPI - PowerBI	
- Built an interactive Power BI dashboard analyzing call center performance data.
- Developed DAX measures for SLA adherence, average handle time, and first call resolution. 
- Created visualizations to track trends, agent performance, and issue distribution.

2. Call Center KPI - Excel	
- Built an Excel dashboard to analyze call center KPIs including SLA adherence, average handle time, and agent performance. 
- Used pivot tables, slicers, and formulas to create an interactive reporting solution.

3. ERP & CRM Analytics System	
- Built end-to-end ERP/CRM data system simulating 300+ transactions across customers, products, and orders 
- Designed relational data model and performed advanced analytics using SQL and Pandas 
- Developed Power BI dashboard with KPIs (Revenue, AOV, Customer Segmentation) improving data visibility 
- Identified key revenue drivers, such as top customers contributing to majority of sales

4. ERP-style-SQL analytics 	
- Designed a relational MySQL database with normalized tables (customers, products, orders, order_details).  
- Performed complex data analysis using JOINs, aggregations, subqueries, HAVING clauses, and window functions to generate insights such as customer lifetime value(Rank customers by spending), top-selling products, and revenue trends.
